把 CSS 插入到 DOM 中。
# 快速开始

首先，你需要安装 `style-loader`：
```shell
npm install --save-dev style-loader
```
推荐将 `style-loader` 与 `css-loader` 一起使用
然后把 loader 添加到你的 `webpack` 配置中。比如：
**style.css**
```css
body {
	background: green;
}
```
**component.js**
```css
import './style.css';
```
**webpack.config.js**
```javascript
module.exports = {
	module: {
		rules: [
			{
				test: /\.css$/i,
				use: ['style-loader', 'css-loader']
			}
		]
	}
}
```
