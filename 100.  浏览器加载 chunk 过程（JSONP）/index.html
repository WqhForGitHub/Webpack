浏览器加载 chunk 过程（JSONP）

打开 DevTools 的 Network 与 Console 面板，再点击下面的按钮。
你会看到浏览器通过插入 <script src="async-feature.chunk.js"> 的方式异步加载 chunk。

JSONP 流程

1. 调用 import('./async-feature')
2. webpack runtime: __webpack_require__.e(chunkId)
3. 创建 <script src="/dist/async-feature.chunk.js"> 插入 head
4. chunk 文件内容：
   (self["myJsonp"] = self["myJsonp"] || []).push([
     [chunkId],
     { "./src/async-feature.js": (m, e, r) => { ... } }
   ]);
5. runtime 监听 myJsonp.push -> 注册 modules -> resolve Promise
6. import() 的 .then(mod => ...) 拿到模块导出
