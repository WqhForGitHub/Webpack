将已存在的单个文件或整个目录复制到构建目录。
# 入门

首先，您需要安装 `copy-webpack-plugin`：
```shell
npm install copy-webpack-plugin --save-dev
```
然后将插件添加到你的 `webpack` 配置中。例如：
**webpack.config.js**
```javascript
const CopyPlugin = require('copy-webpack-plugin');

module.exports = {
	plugins: [
		new CopyPlugin({
			patterns: [
				{ from: 'source', to: 'dest' },
				{ from: 'other', to: 'public' }
			]
		})
	]
}
```
