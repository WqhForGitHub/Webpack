`EnvironmentPlugin`是对`process.env`键使用 DefinePlugin 简写。
# 用法
`EnvironmentPlugin`接受键数组或将其键映射到其默认值的对象。
```javascript
new webpack.EnvironmentPlugin(['NODE_ENV', 'DEBUG']);
```
这等同于以下`DefinePlugin`应用程序：
```javascript
new webpack.DefinePlugin({
	'process.env.NODE_ENV': JSON.stringify(process.env.NODE_ENV),
	'process.env.DEBUG': JSON.stringify(process.env.DEBUG)
});
```
>提示
>未指定环境变量会引发`EnvironmentPlugin`-`${key}`环境变量未定义错误。

# 使用默认值

此外，`EnvironmentPlugin`支持一个对象，该对象将键映射到其默认值。如果`process.env`中未定义某个键，则使用该键的默认值。
```javascript
new webpack.EnvironmentPlugin({
	NODE_ENV: 'development', // use 'development' unless process.env.NODE_ENV is defined
	DEBUG: false
});
```
>警告
>来自`process.env`变量始终是字符串。

>提示
>与`DefinePlugin`不同，`EnvironmentPlugin`会将默认值应用于`JSON.stringify`。

>提示
>`null`和`undefined`的默认值行为不同。对于打包过程中必须提供的变量，使用`undefined`对于可选变量，使用 null。

>警告
>如果在打包过程中找不到环境变量且没有提供默认值，webpack 将抛出错误而不是警告。

**例子**：
让我们来研究一下在测试文件`entry.js`上运行之前的`EnvironmentPlugin`配置会产生什么结果：
```javascript
if (process.env.NODE_ENV === 'production') {
	console.log('Welcome to production');
}
if (process.env.DEBUG) {
	console.log('Debugging output');
}
```
在终端执行`NODE_ENV=production webpack`构建时，`entry.js`会变成这样：
```javascript
if ('production' === 'production') {
	// <-- 'production' from NODE_ENV is taken
	console.log('Welcome to production');
}
if (false) {
	// <-- default value is taken
	console.log('Debugging output');
}
```
运行`DEBUG=false webpack`会产生以下结果：
```javascript
if ('development' === 'production') {
	// <-- default value is taken
	console.log('Welcome to production');
}
if ('false') {
	// <-- 'false' from DEBUG is taken
	console.log('Debugging output');
}
```
